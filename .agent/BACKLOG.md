# BACKLOG.md — Peticiones del Usuario

> **PROPÓSITO:** Este archivo es el inbox del usuario para solicitar nuevas features o reportar bugs.
>
> **REGLAS:**
> - El **usuario** escribe aquí una línea por cada feature/bug
> - El **orquestador** consulta este archivo al inicio de cada sesión y cuando el usuario lo solicite
> - El **orquestador** convierte cada línea en una tarea formal en `TASKS.md`
> - El **orquestador** elimina la línea procesada de este archivo

---

## 📝 FORMATO

Escribe una línea por petición, usando este formato opcional:

```
[FEATURE] Descripción de la nueva funcionalidad
[BUG] Descripción del error a corregir
[REFACTOR] Descripción de la refactorización
[DOCS] Descripción de documentación a añadir
Cualquier texto sin etiqueta se asume como FEATURE
```

**Ejemplos:**
```
[FEATURE] Añadir modo claro/oscuro dinámico
[BUG] La búsqueda no muestra resultados si el query tiene espacios
Implementar skeleton loaders en HomePage
[REFACTOR] Extraer lógica de favoritos a un usecase separado
```
